vBookmarks — 一键即达的书签管理器。

别再在 Chrome 自带的管理器里翻书签了。vBookmarks 把整个书签库装进一个极速弹窗：点一下工具栏图标(或按 Ctrl+Shift+V)，敲几个字母，回车直达。它是经典 Neat Bookmarks 的活跃续作 —— 免费、轻量，自 2011 年持续打磨至今。

为什么你会喜欢它

• 标题、网址、文件夹模糊搜索，毫秒出结果 —— 弹窗、侧边栏、地址栏(输入 * 再按空格)皆可唤起，匹配高亮，中日韩友好。
• 七个专用视图：经典书签树、搜索、标签页组、暂存工作台、访问统计、死链清理、重复清理。
• 命令面板(Ctrl+K / Cmd+K)包揽一切：打开、移动、排序、切视图、换主题，还支持自定义斜杠命令并跨设备同步。

添加与整理，毫不费力

• 星标按钮、Ctrl+D、全局 Alt+Shift+S、右键菜单，四种方式随手存，永远存进你指定的文件夹。
• 一条命令把整个窗口的标签页存成书签文件夹，日后还能作为命名标签页组整体重开。
• 整理同样快：拖拽、多选批量操作、跨文件夹复制移动、按文件夹排序，编辑对话框自动填好一切。
• 每次删除都能撤销 —— 轻点提示条即可找回，清理从此没有心理负担。

真正的全键盘流

• 每个视图都不用碰鼠标：方向键、Home/End、PageUp/PageDown，Enter 打开，F2 重命名，Delete 删除，输入字母直达条目。
• Alt+1…7 直达任意视图，Tab 在区域间循环，Esc 一层层退出菜单、面板、多选与搜索，干净利落。
• 快捷键全家桶：Ctrl+K / Cmd+K 弹窗内呼出面板，Ctrl+Shift+K 全局呼出，Alt+Shift+B 开合侧边栏，Alt+Shift+S 快速添加。

暂存工作台 —— 一种全新的整理形态

• 新书签先落进暂存区，而不是直接淹没进书签树：随手分组、加星、批量归档进文件夹，或者任它们流进"最近添加"时间线。
• "先存后理"从此变成每天五分钟的小习惯。

超越官方管理器的加强

• 真正的分割线 —— 任意文件夹里插入可自定义颜色与粗细的分隔线，这是 Chrome 从未有过的能力。
• 自动补齐缺失的网站图标(直连、代理、服务商多路兜底，本地缓存)，每一行都清晰易读。
• 死链扫描支持代理复检，分得清"网站挂了"与"你的网络访问不了";重复书签按六种保留策略合并。
• 同步状态指示，一眼看出哪些书签只存在这台设备上(需 Chrome 138+)。
• 访问统计完全本地：按次数或最近排序，随时暂停，一键清空。

打造成你的样子

• 四套精制主题：亮色、暗色、墨色、纸感，另有跟随系统、界面缩放、自定义 CSS 和自定义工具栏图标。
• 弹窗或侧边栏：侧边栏让 vBookmarks 成为页面旁常驻的工作台 —— 也是未来更多可能的起点。
• 完整翻译 43 种语言。

免费且安心

永久免费。无广告、无追踪、无需账号，数据从不离开你的浏览器。MIT 协议开源，由一位至今亲自回复每个 issue 的开发者维护。
