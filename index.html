Why vBookmarks

The bookmark manager Chrome forgot to build

It manages the same bookmarks you already have — but adds the speed, structure and cleanup tools the built-in manager never shipped.

Instant fuzzy search

Titles, URLs and folders — matched in milliseconds from the popup, the side panel, or the address bar (type * then Space). Highlighted matches, CJK-friendly.

A ⌘K command palette

Open, move, sort, switch views, change themes — every action has a slash command. Add your own; they sync across devices.

A staging workbench

New saves land in a triage inbox instead of vanishing into the tree: group them, star them, batch-file them — or let them flow into the recently-added timeline.

Window → folder → tab group

Dead-link scan

Duplicate merge

Duplicates grouped by URL, merged in bulk with six keeper strategies — oldest, newest, most-visited and more.

Real separators

Divider lines with custom colors and widths, inside any folder — the feature Chrome's manager never had.

Every deletion is undoable

Cleanup never feels risky — one tap on the toast brings back whole deleted subtrees.

FAQ

Good questions

Is vBookmarks really free?

Yes — free forever, with no ads, no subscriptions and no premium tier. It's MIT-licensed open source, so you can also build it yourself from GitHub.

Which browsers does it support?

Chrome 114 and newer, on desktop. The same package runs on Microsoft Edge and other Chromium browsers that support Manifest V3 extensions.

Does it change how my bookmarks are stored?

No. It manages your existing Chrome bookmarks through the official bookmarks API — anything you organize in vBookmarks syncs wherever Chrome sync does. Preferences and per-device data stay local.

How do I search from the address bar?

Type * in the omnibox, press Space, then start typing. Results come from the same fuzzy ranker the popup uses — titles, URLs and folders.

What is the staging workbench?

A triage inbox for new bookmarks. Instead of dumping saves straight into the tree, vBookmarks holds them in a staging area where you can group, star and batch-file them — or ignore them until your daily five-minute cleanup.

What happened to Neat Bookmarks?

Neat Bookmarks, the beloved minimalist popup, stopped working when Chrome dropped the APIs it relied on. vBookmarks began in 2011 as its direct successor and has been continuously maintained ever since — same spirit, vastly more capability. See the full history and changelog.
