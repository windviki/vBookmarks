## 2. 功能完备性核查（逐项确认落地）

- **过去标注语义**：`markedRows()` 以 `live`/`lastScan` 的结果覆盖集为界，
  未覆盖标注 = 残留；已判死链/受限的标注只骑结果行、不重复计数（9e18841 回归
  修复）。`dead-过去标注语义.md` §2.4 与代码一致。✓
- **标注状态过滤器（全部/已标注/未标注）**：`markFilter` 与 `filter` 正交，
  作用于结果行 + 残留标注列表；`data-markfilter` → `dataset.markfilter` 全小写
  键修复（1740597）。12 组合全矩阵测试（tests 1600-1631）锁定。✓
- **排序（检测时间/路径/标记时间）**：`deadSort` 持久化；结果行与残留行共用
  `compareRows`；老备份无 per-row ts / 无标记时间 → 稳定回退。✓
- **选择工具栏计数**：`markStatusCounts()` 按当前 `filter` 分类划分标注状态；
  残留仅在 全部/上次标注/无扫描 计入；计数不随 `markFilter` 变化（描述分类总量）。
  与主工具条"全部 = 死链 + 受限 + 未覆盖标注"之和一致。✓
- **宽行时间显示**：`meta.subText`（路径左）+ `meta.subRight`（时间右）在
  ≥480px / panel 第二行；窄视口 `.row-sub` 隐藏、`.row-path` 显示路径、时间入
  tooltip（`meta.tooltipAppend`，tree-render 向后兼容增量）。绝对时间
  `toLocaleString`；无标记时间不显示。✓
- **颜色语义统一**：死链=红（`--vbm-danger`）、受限=橙（`--vbm-warning`）覆盖
  pill 填充 / mark ⚑ 按钮（类型色描边↔实心）/ tree overlay（`.dead-indicator`

## 3. 本审计发现并修复的缺陷（4 项）

### 3.1 【P2】选择模式下 M/R 键盘仍操作聚焦行（语义冲突）
`onKey` 在 `selecting` 时仍响应 `M`（toggleMark）/ `R`（revealInTree），而行
点击在批量选择中是勾选成员——键盘悄悄标记/定位单行与点选不一致。
**修复**：`onKey` 入口 `if (selecting) return false`。测试：selecting 下
`onKey('m'/'r')` 返回 false、不改 `deadMarks`、不触发 `revealInTree`。

### 3.2 【P2】"上次标注"分类空态文案误导（全覆盖场景）
`filter='marked'` 且全部标注被本次结果覆盖（残留为 0）时，原显示
`deadMarkedNone`（"还没有标记过书签"）——用户明明标记过，只是都被判进结果行
了。**修复**：`(markedRows().length || deadMarks.size) ? deadNoneFiltered :
deadMarkedNone`——有标注但无可见残留 → 提示换分段；真无标注才说"没标记过"。
更新 2 处既有断言（tests 1139、1869）。

### 3.3 【P3】选择模式下 proxy strip 仍在场（状态混叠）
`selecting` 时 `renderProxyStrip()` 无条件渲染，add/manage 条与批量工具条同屏，
面板可被点开。**修复**：`renderProxyStrip` 加 `if (selecting) return ''`，退出
选择模式恢复。测试：进入 selecting 无 `dead-proxy-strip`，退出后重现。

### 3.4 【P3】选择模式下结果行仍渲染 ⚑/× 按钮（依赖 CSS 隐藏）
`renderRows` 无条件输出行按钮、靠 `.selecting .row-btn {display:none}` 隐藏；
残留行（`renderMarkedRows`）是 JS 条件渲染——两者不一致，多余 DOM 节点对屏幕
阅读器仍可见、点击也落空。**修复**：`renderRows` 与 `renderMarkedRows` 对齐，
selecting 时 JS 层不渲染行按钮。测试：selecting 下 innerHTML 无
`dead-mark-btn`/`dead-del-btn`，行仍在（可勾选）。

## 4. 设计合理性评估

- **镜像架构**（SW 扫、视图 mirror）正确：popup 关闭不中断扫描，storage.onChanged
  驱动渐进渲染，`applyBlob` 容错 corrupt blob。
- **计数语义**自洽："全部 = 死链 + 受限 + 未覆盖标注"，一个 id 不既算结果又算
  标注；主/第二工具条计数同源同规则。
- **颜色双编码**（形状 + 文字 + 颜色）：dead/blocked pill 用文字与符号区分，
  非仅颜色，符合 a11y 要求。
- **tooltipAppend / badgeSlot / subRight** 均为 tree-render 可选 meta 增量，
  其他视图不传零影响（回归锁定）。
- **残留标注列表常驻"全部"视图、仅死链/仅受限隐藏**：避免"工具栏换了但列表还
  是全量"的错位观感，切换分类时残留由各自结果行承接。设计成立。

## 5. 边界 case 记录（评估后保持现状）

- **clearScanResults 保留 filter**：清空后若 filter 停在 仅死链/仅受限，UI 回落
  marked-only/蓝色按钮，需重新扫描才恢复分段——保留用户分类偏好的设计决策。
- **markAll 覆盖已标注行标记时间**：批量动作同一时间戳，已标注行时间被刷新，
  与 markSelected 同语义，可接受。
- **proxyGateError 取消扫描后残留**：取消后 chip 仍显示上一次 gate 失败原因，
  属"最近一次运行"信息，不属错误。
- **scanStarting 卡死**：仅 SW 完全无响应时（启动失败）会发生；MV3 SW 总会挂
  listener 并发布 blob，风险极低，未加看门狗。

## 6. 版本集成风险（需用户决策）

`fix-as-4.0.7` 的 merge-base（`4a148a2`）早于 master 的 favicon 富化特性
（`src/favicon-enrich.js`，4.0.6 引入，master 现为 4.0.8）：**4.0.7 分支不含
favicon-enrich**。若 4.0.7 最终发布，将缺失 4.0.6 已提供的 favicon 富化能力。
建议以 master（4.0.8）为基线合流死链改进，避免版本倒退。本审计不涉及该功能。
