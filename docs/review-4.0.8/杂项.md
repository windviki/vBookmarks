# 杂项

记录一些零碎的改进点。

## 已经完成
- 非搜索视图下清空搜索栏（点 × 或删空文本）现在**无条件持久化**：此前搜索模式已关闭时 quitSearchMode 跳过写入，旧查询下次打开 popup 会恢复。补了 search.js 两处写入 + 单测。
- /version 命令和弹出框，用于一键复制元信息，报bug。
- /lang {code} 命令切换语种。选项页提供语种下拉选项手动选择。
- 选项页分组重新组织：常规、视图之后按视图顺序建立专属分组（书签树/搜索/标签组占位/最近添加/统计/死链/重复书签占位），显示 XX 视图开关统一收归“视图”分组。
- 选择模式键盘焦点：键盘进入选择模式后焦点落到批量工具条第一个可用按钮；键盘退出（退出按钮或工具条上 Esc）后焦点回到恢复后的“选择”按钮；行上 Esc 保持行焦点。
- 首次打开 popup 时横幅右侧控件（捐赠“不再显示”、announce ×）可能被裁剪：body 设为定位包含块，且恢复 popupWidth 时同步写到根元素，窗口首次打开即匹配保存宽度。
- 捐赠横幅视觉：爱心左侧垂直居中，文本与按钮在窄宽度下可换行。
- favicon 直连抓取加 `credentials:'omit'` + `cache:'no-store'`，401 站点（如 roundpic.com）不再可能从 popup 弹出 HTTP 登录框；popup 内 `a.tree-item-link` 默认导航被统一 preventDefault，避免合成 click 漏处理时 popup 自身加载书签 URL。
- 隐藏视图经命令面板进入时弹出的提示 toast：手动切换到其他视图会立即 dismiss，不再残留到超时。
- fuzzy 排序：部分匹配时，命中字符之间的距离作为 ranking 依据——匹配越紧凑排名越靠前。例如输入 `123`，`10.200.31.0` 会排在 `vs1-something2/version3.html` 前面。
- 搜索视图历史行右键误弹完整书签/文件夹菜单：极窄 popup + zoom>100 时，右键落在历史行的时钟/条数/时间等子元素上，context-menu 的 target 归一化先命中 SPAN 而落入文件夹菜单分支。改为优先归一化到最近的 `<a>` 祖先（无 anchor 才回退 SPAN），并给 `#search-history-area ul li a *` 加 `pointer-events: none` 与其他列表行一致；补了单测回归（`src/context-menu.js`、`css/neat.css`、`tests/context-menu.test.js`）。

## 本轮审计修复（2026-08-21，相对 186948b 的复审）

- **toast 随视图切换 dismiss 此前在生产环境是死代码**：ea78d89 把 `dismissToast` 接进了 initTreeView 的 ctx（tree-view 从不读它），真正的消费者是 view-manager。修复把 `initUndo` 提前到 `initViewManager` 之前并以 plain values 传入 `toastAction`/`dismissToast`——首版 lazy getter 修法会在首次视图切换时撞上 `undo` 的 TDZ ReferenceError（单测不可见，Docker 冒烟当场抓获），smoke.js 也补了 #14b 真机断言（toast 在手动切换视图后消失）。
- fuzzy 跨度惩罚的原测试钉不住修复（文档示例在修复前后排序相同）；换成经 brute-force 验证的翻转账对（`web123` vs `12.x......3`，修复前 loose 在前）。
- 语言下拉回退失效：options.js 的 `previous` 在 change 事件后读取（已是新值），setLang 失败时回退到自身。改为跟踪“最后成功应用的值”，补了 options.test.js 行为用例。
- `/lang AUTO`（大写）被拒：normalize 现在大小写不敏感地识别 auto 关键字；损坏的 `vbmI18nDict` 缓存自愈（删键、不报假override）；本机 override 与导入的 uiLanguage 冲突时本机优先并把 storage 收敛到本机值。补了 5 个 i18n-live 用例。
- /version 对话框：公告 textKey 翻译为空时回退英文兜底（与横幅一致）；复制按钮在 writeText 被拒时回落 execCommand，两条路径都失败保持原标签；关闭按钮改为填 label span（不再整体覆写 innerHTML 冲掉 `<kbd>Esc</kbd>`）。补了 4 个 dialogs + 3 个 palette 用例。
- announce DSL 拒绝边界补钉：尾部逗号、op 与版本号分离、不支持的 `!=` 均 fail-closed。
- 注释修正：donation.js 的“30 次打开宽限”注释与行为不符（首次打开即显示一次欢迎卡，随后 30 次内不再询问）；github-source.js 补临时 PAC 在 popup 中途关闭时的残留说明（良性，SW 冷启动清扫兜底）；view-dead/view-dupes 的 selectionFocus 注释改为如实描述互斥关系。
- 文档同步：AGENTS.md 补 i18n-live/version-info 两行、选项页 15→20 分区、面板命令 17→19、对话框 5→8、locale 键 447→465、verify-keyboard 140→142 断言、捐赠宽限表述；双语 changelog 补 9 条遗漏条目（语言切换、/version、公告回退链、选择模式焦点、favicon 登录框、横幅裁切、搜索清空持久化、toast dismiss + fuzzy 跨度、历史行菜单 + get 防护）并把“15 分区”“2394 用例”改为现状；guide-v4 双语命令表补 /version 与 /lang。
