# 杂项

记录一些零碎的改进点。

## 已经完成
- 非搜索视图点击搜索栏的清空，实际上仍然会持久化，下次展开popup仍然留存。
- /version 命令和弹出框，用于一键复制元信息，报bug。
- /lang {code} 命令切换语种。选项页提供语种下拉选项手动选择。
- 选项页分组重新组织：常规、视图之后按视图顺序建立专属分组（书签树/搜索/标签组占位/最近添加/统计/死链/重复书签占位），显示 XX 视图开关统一收归“视图”分组。
- 选择模式键盘焦点：键盘进入选择模式后焦点落到批量工具条第一个可用按钮；键盘退出（退出按钮或工具条上 Esc）后焦点回到恢复后的“选择”按钮；行上 Esc 保持行焦点。
- 首次打开 popup 时横幅右侧控件（捐赠“不再显示”、announce ×）可能被裁剪：body 设为定位包含块，且恢复 popupWidth 时同步写到根元素，窗口首次打开即匹配保存宽度。
- 捐赠横幅视觉：爱心左侧垂直居中，文本与按钮在窄宽度下可换行。
- favicon 直连抓取加 `credentials:'omit'` + `cache:'no-store'`，401 站点（如 roundpic.com）不再可能从 popup 弹出 HTTP 登录框；popup 内 `a.tree-item-link` 默认导航被统一 preventDefault，避免合成 click 漏处理时 popup 自身加载书签 URL。
- 隐藏视图经命令面板进入时弹出的提示 toast：手动切换到其他视图会立即 dismiss，不再残留到超时。
- fuzzy 排序：部分匹配时，命中字符之间的距离作为 ranking 依据——匹配越紧凑排名越靠前。例如输入 `123`，`10.200.31.0` 会排在 `vs1-something2/version3.html` 前面。
