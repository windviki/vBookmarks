## 二、决定保留现状（含理由）

| 项 | 决定 | 理由 |
|---|---|---|
| B2 | 保留 | 捐赠卡 + 本地 what's-new 同帧叠加是一生一次版本门场景；让位会导致 what's-new 永不显示，观感代价小于丢失信息。 |

| D8 | 保留 | SW 侧 storage 写失败无 UI 出口；补 toast/横幅需要新状态面，属 4.1.0 范围。当前失败后果 = 该轮扫描结果丢弃，可重扫恢复。 |
| F3/F4/F5/F6、D14/D16 | 保留 | 审计原文已明确划入 4.1.0 或记录备查：L2 页面本体语义变更、DDG 占位指纹需实测、服务商增补、hydrate 全量读优化、控制区层叠与 live 渲染性能量级优化。 |
| B4 去留 | 保留 | 仅补代码注释；是否从正式版移除属商店审核策略决策，不在此次功能收尾内。 |
