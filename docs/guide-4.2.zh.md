## 1. 全新的标签系统

文件夹只能装下一本书签一次;标签让它同时属于「工作」「阅读」「later」。4.2 的标签系统是一层**跨文件夹的彩色组织**——九种颜色取自 Chrome 自己的标签组色板,在所有主题里恒定——并且与搜索视图长成一体:搜索框既是搜索框,也是标签语言的第一现场。

### 打标签,随手就是

- **右键任何书签** → 标签子菜单全量列出标签,单击即打/摘。
- **行悬浮打标钮**:搜索与暂存视图里,鼠标掠过行尾即现。
- **选择态批量打标**:多选一批行,选择工具条上的打标签一次作用全批。
- **选择器内就地建标**:选择标签时输入一个新名字,「＋新建」行即现,自动配色。
- **保存时打标签**:快速添加星标(或 `Ctrl/Cmd+D`)照旧保存页面——确认 toast 现在附带一个**「添加标签…**」动作,单击即为这本新书签打开标签选择器。归档发生在落笔那一刻,零二次整理。不点它,流程与原先逐字节一致。
- **大屏检查器**:右侧详情面板的标签区,chip 悬浮 × 可移除、无标签书签有常显打标钮。

新建标签对话框支持**「保存并继续新建」**——当前标签连名字带颜色落定后,名字清空、颜色留在原位、对话框原地待命,一口气建一批标签;被拒绝时(重名 / 满 100 上限)名字原地保留、就地说明原因。

### `#` ——搜索框里的标签语言

在搜索框输入 `#`,唤起**标签建议面板**:按名字自动补全,点击或 Enter 完成一个词元。之后:

- `#工作 #阅读` 多词元取**交集**;`-#工作` **排除**;`#!` 列出**没有任何标签**的书签。
- 标签词元与字段词元**自由组合**:`#工作 site:github.com` 是一条查询。
- 激活的词元以可移除的 **× chips** 停在结果工具栏上;结果集还自带一行**「在此结果中:」共现标签条**——点一枚就追加一截 AND 词元,它紧贴计数条,正落在你已经在看的地方。
- `#标签` 成员查询的组头有**「全部显示 / 全部隐藏标签」**一对方向钮,一次手势作用于整个结果集。
- 命令面板裸 `/tag` 列出全部标签与计数,回车即跑成员查询;`#` 建议面板页脚带动作条(查看全部 / 新建标签 / 标签管理页),整面板纯键盘可走完。

搜索视图的**空闲面**就是标签工作台:顶部的**热门标签条**(top-8 推荐,超量收进 +N 徽标,右端「添加标签」入口;零标签时是一行直达新建的引导)+ 最近搜索列表(可整列折叠)。哪枚标签常点,哪枚就在手边。

### 行上的标签,长什么样

每行书签的标签以**六档样式**之一呈现——淡底药丸(默认)、实底药丸、描边药丸、`#` 彩字、圆点、不显示——在设置里全局切换。放不下的溢出折叠为 `+n`,**点击就在那一行就地展开**(全量 chips + `−` 收起钮,Esc 也收)。行内 chip 处处同义:**点标签即跑它的 `#标签` 成员查询**——树、搜索、暂存、统计、死链、去重与标签页分组视图,无一例外。想让某一行安静又不删标签?「在此行隐藏该标签」的逐行掩码正为此而生。

### 标签管理页

右键标签(或 `#` 面板的「管理标签」)进入 master–detail 管理页:左列标签表——WYSIWYG 药丸与行内完全同款、实时计数、逐标签显示开关——驱动右列成员面板:批量重指派、打开/复制、逐成员隐藏。**重命名冲突即合并**、改色、把整个文件夹灌成标签、Raindrop `#tag` 互操作导入导出、整体重置。删除标签无论走哪条路径,写入前都会快照分配关系——**撤销原样回放**,四条删除路径共用同一张安全网。

### 跨设备,按设计行事

标签依托书签 guid,经 `chrome.storage.sync` 同步。没有逐节点 guid 的 Chrome(< 138)上标签严格留在本机,浏览器升级的瞬间由晋升路径无损并入 sync 档——不静默丢失、不跨设备错挂。写入超出存储配额时有一次提醒,本机镜像继续可用。

## 2. 独立工作台

独立窗口——此前只是某个视图的单薄弹出——现在是一张完整的桌面工作台,布局语言取自 chrome://bookmarks 与 Raindrop。

**四条入口:**

- 任意视图头部的弹出按钮(可用 `showStandaloneButton` 关闭)。
- 命令面板:`/open`(别名 `/standalone`)。
- 直接走 URL:`pages/standalone.html?view=…`。
- **自定义命令**新增的「打开独立工作台」动作——像其他自定义命令一样,可指定启动视图与打开位置(标签页 / 窗口 / 后台)。

**进去之后,哪里不一样:**

- **带文字的左侧导航轨**取代顶部标签条——七个视图全部带名字,滑动指示器,RTL 自动镜像。宽窗口终于放得下文字了。
- **三种形态,三份记忆**:弹窗、侧栏、独立窗口各自记忆自己的上次视图。独立窗口埋在「去重」上,不会再把你的弹窗从「树」上拽走。
- 头部新增**新建书签 / 新建文件夹**按钮,落点是树中焦点所在的文件夹(回退到快速添加根目录)。对话框优先:取消就不建。
- **宽画布双栏。** 画布宽度按 1200 / 1480 px 两档自动步进(也可在独立窗口偏好里钉死宽幅或全幅)。宽窗下,第二栏把**暂存视图**常驻钉在右侧:左侧任意浏览,树行直接拖过栏间距扔进去——或用选择工具栏的「发送到暂存」——右栏实时更新,批量归档一气呵成。栏宽可拖调,不需要时可以收起。
- **窗口标题跟随当前视图**,任务栏一瞥就知道自己趴在哪张桌上。
- **主页总览**加入导航轨:当日问候、一键 新建/暂存/死链扫描 动作、四张计数卡(书签总数 / 暂存收件箱 / 死链 / 重复组——与导航轨徽章同源的数字),以及最新书签的普通行列表。可在独立窗口偏好里把它设为落地视图。
- **中央列表的三种形态。** 头部的**形态菜单**(当前形态图标)显式列出 **列表 / 紧凑 / 卡片** 三档——当前视图不可用的档位置灰,「哪些视图支持哪种形态」一目了然:紧凑保留单行标题、踩 28px 节拍;卡片把平铺列表(暂存 / 最近添加 / 主页)重排成 favicon 卡片网格——同一批行、同一套悬浮钮、同一套键盘走位,只有几何变了。自带工具条的视图(统计 / 死链 / 去重 / 标签组)与结构性的树和搜索保持自己的形态——形态按视图自动钳制。
- **右栏的详情检查器。** 头部 `[暂存 | 详情]` 开关(或调色板 `/inspect`)给宽窗右栏换租户:面板跟随焦点行——树行、搜索命中、暂存卡片——展示全貌:大 favicon、路径面包屑、标签 chips(点击即跑 `#标签` 成员查询)、访问次数、总停留时长、死链判定与暂存状态,打开 / 复制 / 编辑 / 打标签 / 送暂存 / 删除 一键可达。所有动作都走你熟悉的同一套对话框、确认与撤销 toast——面板绝不绕过既有写路径。

键盘跟随布局,而不是布局迁就键盘:Tab 环在钉驻的暂存栏获得停靠点,方向键把两栏当作一个连续空间(完整适应矩阵见 `docs/keyboard-model.md`)。

## 3. 跨窗口拖放

4.2 把侧栏与独立窗口搬上**原生 HTML5 拖放管线**,而原生拖放会话正是唯一能跨越窗口边界的东西:

- **树 ↔ 树**:把一行从侧栏的树拖到独立窗口的树(或反向)——书签完成移动,来源窗口自行刷新。分区法则与窗口内一致(决策内核为两条管线共享)。
- **来自任何地方的链接**:从任意页面、任意窗口拖出一个 URL,落在**暂存面板**上,它就作为一条未收藏的暂存行进入收件桶——整张工作台变成浏览器的投放目标。改落在**树**上,则按落点位置新建真实书签(仅限 http/https;懂礼貌的拖放源还会顺手把标题带上)。
- **标签跨窗口**:在两个不同窗口里打开的「标签组」视图之间互拖标签行——标签即在窗口间搬家。两扇面对面的标签组视图,现在是一种手工再平衡会话的方式。

## 4. 按显示面积分级的三种形态

一套代码,三副身板:**弹窗**保持 320 px 的一瞥;**侧栏**是常驻伴随;**独立窗口**是书桌。视图标签条现在随身板分级:

- 弹窗与侧栏只钉住四个*伴随*视图——树 / 搜索 / 标签组 / 暂存——统计 / 死链 / 去重收进尾部 `⋯`,其角标聚合三者的危险计数。`Alt+数字` 与命令面板照旧直达一切。
- 独立窗口的导航轨全量列出七项(§2)。

各列表视图的选择工具栏还补上了**复制所选**(标题 + URL),紧邻删除。

## 5. 统计视图学会停留时长

访问统计数的是*打开次数*;4.2 补上你实际停留的时间。服务工人(service worker)按 URL 记账**前台停留时长**,账本跨浏览器重启存活,数字因此经得起长会话考验。统计视图新增停留时长排序与每行的时长 pill;重复书签共享同一 URL 的总时长——一条停留时长很大却没有书签的 URL,正是「你该收藏它」的信号。与访问计数一样,停留时长只留在本机,并随统计数据一并清空。

## 6. velvet 视觉语言

### 6.1 一条 token 链,十一个条目

UI 用到的每一种颜色都流经同一个 `--vbm-*` token 词表;主题就是加载在结构层 CSS 之后的一张 token 表。`/theme` 在十三个条目间切换——auto(跟随系统)/ light / dark / ink / paper / classic / classic-dark / dracula（显示名 **Dracula (@Andrew)**，作者 Andrew 的集成版）/ solarized-light / monokai-pro / dracula-remake（显示名 **Dracula**，spec 重制版）/ quiet-light / github-light-hc——`/theme dr` 这类前缀也认。

### 6.2 灰阶先于色相

每个主题的结构层是一架**灰阶梯**:三个平面(canvas / surface / elev)与三级文字(fg / muted / subtle)。色相是*染在固定明度上的氛围*——主题可以给 token 染色,但永远不许改动梯子的次序:hover 与 selected 必须始终可分,muted 文字必须始终可读,任何皮肤都不例外。这不是约定而是门禁:CI 里跑纯数学对比度断言(fg ≥ 7:1、muted ≥ 4.5:1、平面明度单调),真浏览器探针再给每个主题套灰度滤镜截图,断言抽掉色相之后梯子依然成立。

### 6.3 光有方向

浮起是被*照亮*的,不只是被叠高:冷色主题里平面越往上越冷越白(浮层离光源最近),暖色的 *paper* 反其道而行——越往下越暖越深。发丝线与浮层阴影携带同一温度,于是悬浮在页面上的对话框在任何主题里都读作「光从上来」。

### 6.4 主题是文件,密度不是主题

选项页的**主题管理器**可从纯 CSS 文件导入主题包——先过 token 词表校验,再做 WCAG-AA 对比度预检,然后才允许上身。导入的或手写的主题样式住在**自定义 CSS 工作台**里(多样式、可排序、可逐条开关),不再是埋没的文本框。**行密度**(紧凑 → 宽松)是独立设置,与皮肤正交:任何主题 × 任何密度。

主题组下方挂着两行外链:**主题编写指南**(教你怎么写一个主题包)与**官方示例主题下载**(GitHub `docs/samples` 目录,内含吃满全部狂热通道的 aurora-bench 炫技样本)——下载 `.json` 主题包后经「导入主题包」上身,所见即所学。

### 6.5 暂存图形语言与一次性动效

「收藏与否」有一套统一图形文法:**空心飞机**悬浮浮现 = *未暂存*;accent 色的**实心飞机**常显 = *已暂存*。标签的标记钮沿用同一文法(空心 tag → 实心 tag)。切换一律**在位翻转**——行永不重渲染,文件夹头把翻转级联给子行——而动效只属于 ON 转换:星标在保存落定瞬间 pop 一次,飞机/tag 在入列瞬间滑入。已暂存的行重渲染时保持静止;`prefers-reduced-motion` 全局钳制兜底。

### 6.6 几何律

内容周边的铬件遵循一小组硬性规则,由测试看守:每个列表的末位行按钮、每条工具栏的末位图标、每个组头的尾钮,都坐在距容器右缘 **8px 的同一条轴**上;图标钮一律 **20px 盒、4px 均匀步距**;选择模式是**两行 rung**——上行计数与 全选/反选/清除,下行图标化批量动作,其文字标签随可用宽度逐个点亮;**danger 红永远居右**;标签 chips 仍是两槽几何(窄面住行尾、宽面独占一行),溢出收进一枚 `+n`。**带标签的行读作 标题 → 标签 → 元信息**:标签是你亲手打的身份,路径/时间是派生上下文,殿后。点 `+n` 就在**那一行标签行上**就地展开——全量 chips 加一枚 `−` 开关,不复制第二遍、不掉到 meta 之下孤悬;`−` 或 `Esc` 收起。放不下的东西折进 `⋯` 菜单或经容器查询图标化——绝不换行成视觉噪音。

### 6.7 标签穿上这套语言

九个标签颜色是 **Chrome 自己的标签组色板,跨所有主题恒定**——你的 `#工作` 在 light 和 dracula 里是同一个蓝。chips 有六档显示样式(淡底药丸——默认、实底药丸、描边、`#` 彩字、圆点、不显示),对比度由计算契约看守:一套色墨公式覆盖九色 × 全部主题,WCAG AA 有测试背书。标签管理页跟随当前主题。

chips 出现在哪里就是同一个意思——树、搜索、暂存、统计、死链、去重与标签页分组视图:**点标签即跑它的 `#标签` 成员查询**,点 `+n` 即就地展开该行 chips。标签页分组视图里,点 chip 永远不会打开它所在的那个标签页。

### 6.8 个性,拴着缰绳

纪律之内,主题可以说话:文件夹图标取主题的文件夹色相,结构先于装饰被扫到;*ink* 带着呼吸感的微光,*Dracula (@Andrew)* 挂霓虹 accent 光条(本机装了 Exo 2 才点亮该字体——永远不用网络字体),*paper* 以朱砂回敬。而留给老用户的:**classic / classic-dark** 复刻 v3 观感——配方见 v4 指南的[经典外观一节](guide-v4.zh.md#5-找回经典的外观与手感)。

## 7. 从 4.1.x 升级

- **标签系统是 4.2 的新居民**:你的书签、文件夹、暂存区与统计原样随行;标签从零开始——右键一本书签打上第一枚,或把一个常用文件夹「灌成」标签(标签管理页 → 文件夹灌入),两分钟就有第一张 `#` 查询。
- **从 4.1.0–4.1.1 跳级升级**:4.2.0 同时包含 4.1.2/4.1.3 的滚动记忆修复(深滚动位置在慢机器上存活;高亮不再拖拽重开视野)。
- 完整的逐版清单见[更新日志](README.zh.md#v420)。
