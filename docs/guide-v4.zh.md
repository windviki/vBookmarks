## 1. 视图系统总览

4.0 把弹窗从"一棵树"升级为**六个视图**，顶部是图标 tab 条：

![视图 tab 条与各主题](images/guide/tabs-themes.png)

| 视图 | 作用 | 直达键 |
|---|---|---|
| 树 Tree | 经典层级书签树（默认启动视图） | `Alt+1` |
| 搜索 Search | 双区搜索：上区历史、下区结果 | `Alt+2` |
| 最近 Recent | 最近添加，按今天/本周/本月/更早分组 | `Alt+3` |
| 统计 Stats | 本地访问统计 + 最近访问分区 | `Alt+4` |
| 死链 Dead | 双通道死链扫描，可暂停/恢复 | `Alt+5` |
| 重复 Dupes | 重复书签清理，六种保留策略 | `Alt+6` |

（直达键是 `Alt+1…6`，作用于当前可见的视图。`Ctrl/Cmd+1…6` 作为旧孪生键在浏览器放行的场合仍然有效——Chrome 弹窗/侧边栏可以——但 Edge 把 `Ctrl+1…8` 保留给切换浏览器标签页，所以 `Alt` 是全平台通用的写法。）

（tab 上是每视图一枚 16px 线条图标 + 本地化标签，窄宽度下标签自动隐藏只留图标。）

- **角标**：tab 上的数字徽章实时显示该视图的要事数量（死链标记数、重复组数、已统计条目数）；可在设置里关闭"在视图标签上显示数量角标"（`showTabBadges`）。
- **显隐**：设置 →"视图"分组里可单独隐藏统计/死链/重复，或整条隐藏 tab 条（见 [§5](#5-回到经典外观与行为)）。
- **弹窗 vs 侧栏**：两者默认都会在你上次离开的视图重新打开——弹窗靠的是"记住上次所在的视图"（`rememberView`，默认开；关掉则总是从树启动），侧边栏（设置开启 `openInSidePanel`，`Alt+Shift+B` 呼出）则始终记住，随时可当作常驻工作台。

## 2. 全键盘操作手册

4.0 的键盘模型是**一套语义、处处一致**：你在树视图里养成的肌肉记忆，在其余五个视图原样生效；而且整套模型会随你的设置自动重排——隐藏 tab 条、禁用某些视图或头部按钮之后，每个键在剩下的界面上照常工作，无需重新学习。完整设计（规则、Esc 分层、选项组合适配矩阵）见 [keyboard-model.md](keyboard-model.md)，本节是实用手册。

### 2.1 焦点区域模型

方向键的走位与眼睛扫视界面的顺序一一对应——`↓`/`↑` 在视觉层之间上下穿越，`←`/`→` 沿当前层移动：

```
┌ 头部：搜索框 → ☆快速收藏 → ⚙工具 ┐  ←/→ 沿本行移动 · ↓ 到 tab 条
├ （横幅，仅在出现时可 Tab 到达）    ┤
├ Tab 条：六个视图 tab              ┤  ←/→ 切换 · ↑ 搜索框 · ↓ 下一层
├ 工具行：统计/死链/重复视图顶部      ┤  ←/→ 走控件 · ↑ tab 条 · ↓ 列表
├ 列表：当前视图的行                ┤  首行 ↑ → 工具行（无则 tab）
└───────────────────────────────────┘
```

- 搜索框里按 **`↓`** → 落到当前 tab；**再按 `↓`** → 进入下一层：统计/死链/重复视图先停在**顶部工具行**的第一个控件，再按 `↓` 才进列表（落在记忆行上）；树/搜索/最近视图没有工具行，直接进列表。
- 列表**首行再按 `↑`** → 跨到工具行（没有则跨到当前 tab）；工具行**再按 `↑`** → tab；**再按 `↑`** → 搜索框。（隐藏 tab 条时，链路在余下的层之间直通。）
- 工具行内 **`←`/`→`** 按阅读顺序走遍所有可用控件，到边停住（RTL 镜像）。**控件的原生语义优先**：下拉框（重复视图的策略/范围）的 `↑`/`↓` 保留原生行为（切换选项），要离开它请用 `←`/`→`；按钮与复选框的 `↑`/`↓` 则是离开本层。
- 工具行会随列表一起重绘（排序切换、扫描进度、重新分组）——**焦点会原位恢复**，不会被打断。
- 头部行按 **`→`**——光标已在文本末尾时——从搜索框移到快速加星，再到工具按钮；**`←`** 沿路返回搜索框，光标停在末尾可直接打字。RTL 语言自动镜像。
- **`Tab` 同样可行**：`Tab` / `Shift+Tab` 按同一区域顺序循环——头部控件 → 横幅按钮（仅在横幅出现时）→ tab 条 → 当前视图的列表内工具行（统计排序、死链扫描控制、重复清理策略）→ 列表行——到头回卷。右键菜单、对话框与命令面板内保留各自的局部 `Tab`。
- **焦点记忆**：从列表按出去再回来，落点是你离开时的那一行，而不是顶部。
- **搜索视图例外**：搜索框是搜索视图自身的主控件——有查询词时 `↓` 直接进结果区（空盒时进历史区；历史区 `↓` 越底跨进保留的结果区）。两个区的**越顶 `↑`** 仍走通用跨区：tab 条 → 搜索框。

### 2.2 通用键位（树 + 全部列表视图一致）

| 键 | 行为 |
|---|---|
| `↑` `↓` | 上/下移动选中行（首行 `↑` 跨到视图工具行，无则 tab 条） |
| `Home` / `End` | 首行 / 末行（Mac：`Cmd+↑` / `Cmd+↓`） |
| `PageUp` / `PageDown` | 按视口翻页 |
| `Enter` / `Space` | 打开书签（`Ctrl/Cmd+Enter` 新标签页；`Shift+Enter` 新窗口） |
| `→` | 打开当前行右键菜单（树中文件夹：先展开） |
| `←` | 关闭右键菜单（树中文件夹：收起/回父级） |
| `F2` | 重命名 / 编辑 |
| `Delete` | 删除（**可撤销**：底部 toast → 撤销；非空文件夹先确认） |
| 键入字母数字 | 树与搜索视图：键入过滤（500ms 缓冲连续匹配） |
| `Ctrl+F` | 聚焦搜索框 |
| `Esc` | 分层退出，见 §2.4 |

### 2.3 视图专属键与直达键

| 键 | 在哪里 | 行为 |
|---|---|---|
| `R` | 搜索/最近/死链/重复 | **在树中定位**当前行 |
| `K` | 重复 | 把当前行设为该组**保留项** |
| `M` | 死链 | 给当前行**打/消死链标记**（红 ✕ 全视图同步） |
| `Alt+1…6` | 任意处 | 直达第 N 个可见视图（`Ctrl/Cmd+1…6` 是旧孪生键——Chrome 弹窗/侧边栏里可用，但 Edge 把 `Ctrl+1…8` 保留给了浏览器标签页切换） |
| `Ctrl/Cmd+K` | 弹窗内 | 命令面板 |
| `Ctrl/Cmd+Shift+K` | 全局（任意页面） | 呼出弹窗并打开命令面板 |
| `Ctrl/Cmd+D` | 弹窗内 | 快速收藏当前页（已收藏则打开编辑） |
| `Alt+Shift+S` | 全局（任意页面） | 把当前标签页直接收进快速收藏文件夹 |
| `Alt+Shift+B` | 全局 | 打开侧边栏模式 |

tab 条本身：`←` `→` 切换并激活（RTL 语言自动镜像）、`Home`/`End` 跳首末、`↑` 到搜索框、`↓` 进视图工具行（无则列表）。

### 2.4 Esc 分层链

`Esc` 永远只剥最内一层，从不清空一切：

```
右键菜单 → 横幅（消除 = "稍后"） → 命令面板
        → 视图级动作（死链：暂停/续扫；死链/重复：退出选择模式）
        → 清空搜索词 → 回到树视图 → 关闭弹窗
```

例：死链扫描中按一次 `Esc` = 暂停（再按续扫），不会误清你的搜索词。

### 2.5 命令面板键盘

`↑↓` 选行；`Enter` 执行；`→` 对书签行打开右键菜单（对自定义指令行则打开该指令的编辑/删除菜单）；继续打字即时缩小范围；`Esc` 关闭。失焦（点击别处）自动关闭。

## 3. 逐视图上手

### 3.1 搜索视图——双区结构

![搜索双区：上区历史、下区结果](images/guide/search-dualzone.png)

- **上区·最近搜索**（MRU 10 条）：每条显示查询词、结果数、相对时间。
  - 记录时机（避免增量前缀刷屏）：按 `Enter` 搜索、打开任意结果、或离开搜索视图时。
  - **重跑**：点击 / 选中后按 `Enter` / `→` 或右键菜单"重新搜索"。
  - **删除**：行尾 `×`（hover 或键盘焦点显现）、`Delete` 键、或 `→` 右键菜单；头行"清空"一次清完。
- **下区·结果**：离开视图再回来，搜索框文字、结果、滚动位置**原样保留**——切去看统计再切回，东西都在。
- 相关设置：`searchAfterEnter`（按 Enter 才搜，默认即时搜）；`searchHistoryEnabled`（关闭即停记**并清空存量**）。

### 3.2 最近视图

![最近视图](images/guide/view-recent.png)

- 最新书签按**今天 / 本周（7 天）/ 本月（30 天）/ 更早**粗分组；行右侧相对时间，窄态行尾、宽态第二行显示 `路径 · 精确时间`。
- 条数在设置里调（10/20/50/100，默认 20）。
- `R` 或右键菜单"在树中定位"跳到该书签在树里的位置。若开启了"仅显示书签栏"而目标在栏外，会弹出提示 toast 而不是静默失败——点 toast 上的"显示全部并定位"可在本次会话内显示完整树并完成跳转。
- 若看到历史权限条幅：那是可选的一次性导入（见 §3.3），可以点"启用"也可以忽略，不影响本视图。

### 3.3 统计视图

![统计视图](images/guide/view-stats.png)

- **计数从哪来**：①你从本扩展打开书签（弹窗/侧栏/搜索/各视图）；②后台采集器匹配你从地址栏等其它入口打开的书签 URL——两处去重，一次打开只计一次。
- 行显示次数徽章 + 最近访问相对时间；排序按**次数**或**最近**（选择会记住）。
- **最近访问分区**（可选）：开启后读取 Chrome 历史，已收藏的显示 ★，未收藏的按 ☆ 一键收进书签；每行附最近访问的绝对时间（宽屏下与路径同行，右侧保留相对时间徽章）。首次使用会请求 `history` 权限——拒绝/忽略则整个分区不出现，统计照常工作。
- **隐私开关**：设置里关掉"访问统计"立即停采（一行都不写）；视图底部和设置页都有"清空统计"按钮（需确认）。

### 3.4 死链视图

![死链视图](images/guide/view-dead.png)

- **开始**：空态会告诉你共有多少书签待扫，点"开始扫描"。结果**逐行流入**，不用等扫完。
- **后台执行**：扫描跑在 service worker 里而不是页面里——扫到一半关掉弹窗或侧边栏也不会中断，重开就是进度的实时镜像（即使浏览器重启，被打断的扫描也会自行续跑）。取消则回退到上次完成的快照，扫完的结果下次打开即时呈现。
- **控制**：`Esc` 暂停/续扫（进度不丢）。
- **实时但安静**：进度推进只刷新列表内容，**不动你的滚动位置与焦点**——扫到一半滑到很下面看结果，不会再被弹回顶部。
- **先备份**：首次进入会显示风险横幅（接下来是批量改动），附 Chrome 官方备份与恢复说明的链接；点"不再提示"后到下一个大版本前都不再出现，点 × 则本次会话不再出现。
- **双通道**：直连失败时，由你配置的**代理模板**（选项页 →"死链扫描"分组，留空=仅直连）终判。徽章分**死链**（红）与**受阻**（琥珀）——"全世界都挂"与"只是这里被墙"一目了然。
- **过滤**：全部 / 仅死链 / 仅受阻。
- **标记**：`M` 或行尾按钮打标后，红 ✕ 会跟到树、搜索、最近、统计所有视图；批量标记/取消在工具行（有确认）。
- **选择模式**：工具行的"选择"会把闲置控件换成批量条——对过滤后的行做 全选 / 反选 / 清除，然后一键"标记所选"/"取消标记所选"（不再二次确认：显式选择本身就是确认）。`Esc` 退出选择模式。

![死链视图选择模式](images/guide/dead-select.png)
- **调参**（选项页 →"死链扫描"分组）：并发 1–16（默认 4）、超时 2–30 秒（默认 8）。

### 3.5 重复视图

![重复视图](images/guide/view-dupes.png)

- **怎么算重复**：URL 先归一化——剥掉 `utm_*`/`fbclid`/`gclid` 跟踪参数、去掉 `#hash`、根路径尾斜杠——再按 URL 分组；工具行勾选"忽略 http/https 差异"可把 http/https 变体并成一组。
- **先备份**：与死链视图相同的风险横幅会在你首次清理前出现——"不再提示"后到下一个大版本前都不再显示。
- **保留策略**（工具行下拉，六种）：最旧 / 最新 / 书签栏优先 / 最短标题 / 最浅层级 / 最常访问（读统计视图真实数据；统计关闭时置灰）。
- **手动钉选**：点行首单选钮或按 `K`——手动选择跨策略切换保留。
- **组内成员行**：`Enter`/`Space` 打开该副本，`←` 跳回组头。组头自己的右键菜单（右键或 `→`）提供"清理本组"与展开/收起。
- **选择模式**：工具行的"选择"切换到以**组**为单位的批量条（全选 / 反选 / 清除）；"去重所选"经一次确认后清掉所有选中的组。`Esc` 退出选择模式。

![重复书签视图选择模式](images/guide/dupes-select.png)
- **先预览，后执行**：除保留项外全部划线标红预览；点组头 `✓`（应用本组去重——tooltip 写明保留谁、删几条）或"全部应用"才动手。批量删除走**撤销链**，结束只弹一条汇总 toast。
- 范围可限定"仅书签栏"；上次结果有快照，重开即时绘制、后台校验漂移。
- 组头 URL 过长时**中段省略**（头尾都看得见），完整 URL 在 tooltip 里。

## 4. 命令面板

![命令面板](images/guide/palette.png)

- **呼出**：弹窗内 `Ctrl/Cmd+K`；任意页面 `Ctrl/Cmd+Shift+K`（会唤起弹窗并预开面板）。
- **三种用法**：直接打字 = 模糊搜书签与文件夹（书签回车即开，文件夹回车**跳进树**）；`/` 开头 = 斜杠命令（前缀匹配，如 `/d` 同时列出 `/dead` `/dupes`）；空查询 = 完整命令表。
- **命令表**（括号内是别名）：`/add`（`/star`）快速收藏当前页 · `/new` 收藏当前标签页 · `/folder`（`/mkdir`）新建文件夹 · `/session`（`/save`）窗口标签页存为会话文件夹 · `/tree`（`/home`）· `/search`（`/find`）· `/recent`（`/latest`）· `/stats`（`/visits`）· `/dead`（`/broken`）· `/dupes`（`/dedup`）——每个视图一条跳转命令 · `/theme` 加主题名换主题（`/theme dark`，唯一前缀如 `/theme d` 也行；裸 `/theme` 显示用法）——也可以直接用 `/dark` `/light` `/ink` `/paper` 切换 · `/tabs` 切换 tab 条显隐 · `/options`（`/settings`）。
- **自定义指令**：在选项页"命令"分组里定义自己的斜杠指令——打开某个 URL、用剩余词填充 **URL 模板**（`/g kimi code` → `…q=kimi%20code`）、把整个书签**文件夹开成一组标签页**、或带预设跳进某个**视图**（比如固定"保留最新+全部范围"的去重视图、或进入即开扫的死链视图）。最快的入口：直接输入一个命令表里没有的 `/名字`，用出现的"存为指令"行——编辑器会以该斜杠名预填打开。自定义指令参与斜杠匹配（按使用频次排序，别名一并匹配），带 custom 标签，随同步区跨设备同步；对它按 `→` 可打开编辑/删除菜单。
- **桥接行**：普通查询最下方有"在搜索视图中搜索 …"，回车送进完整搜索视图。
- **框周小件**：输入框内的 × 按钮清空查询（纯鼠标件，与搜索框同款）；底部正中有整条关闭栏，方便鼠标用户——键盘退出走 `Esc`。
- 面板失焦自动关闭；`Esc` 逐层退出。

## 5. 回到经典外观与行为

4.0 的每个新界面都能关掉。**最快的路子**：选项页"视图"分组里的 **"一键恢复经典界面"** 按钮——一次点击关闭命令面板、快速收藏星标、工具按钮与视图标签栏，每一项都能在上方单独打开回来。想精细调节，照这个配方来：

| 想要 | 设置（选项页 →"视图"分组，除注明外） |
|---|---|
| 没有 tab 条，单栏树 + `Ctrl+F` 搜索（= 3.x 布局） | 关闭 **"显示视图标签栏"**（`showViewTabs`）。树与搜索仍是唯二视图，快捷键照旧 |
| 再精简一点 | 单独关闭"显示统计/死链/重复视图"（`showStatsView`/`showDeadView`/`showDupesView`），或关掉"最近"（`showRecentBookmarks`）——tab 消失，`Alt+数字` 直达键与面板命令同步失效 |
| 不要命令面板 | 关闭 **"启用命令面板"**（`paletteEnabled`）——`Ctrl/Cmd+K` 与全局唤醒一并失效 |
| 不要星标与工具按钮 | 关闭 `quickAddEnabled` / `showToolButton`（视图分组） |
| 总是从树启动 | 关闭 **"记住上次所在的视图"**（`rememberView`） |
| tab 上不要数字角标 | 关闭 **"在视图标签上显示数量角标"**（`showTabBadges`） |
| 经典配色 | 常规 → 主题选 **亮色** 或 **暗色**（Ink/Paper 是 4.0 的新面孔，auto 跟随系统） |
| 不留搜索历史 | 关闭"搜索历史"（`searchHistoryEnabled`）——立即停记并**清空存量** |
| 不要访问统计 | 关闭"访问统计"（`statsEnabled`）——立即停采；再点"清空统计"抹掉数据 |
| 行尾不要路径标签 | 关闭"显示项目路径"（`showItemPath`） |
| 按 Enter 才搜索（3.3 就有的旧习惯） | 常规 → `searchAfterEnter` |
| 弹窗别记上次状态 | 常规 → 取消"记住上次状态"（`dontRememberState`） |
| 弹窗固定高度 | 常规 → 关闭"自动调整高度"（`autoResizePopup`） |

还想再像一点？选项页的 **"自定义样式"** 分组给你完整的 CSS 控制权（如 `* { font-family: Consolas; }`），配合 **"自定义图标"** 分组换掉工具栏图标，外观可以完全按旧习惯定制。全部设置改动即时生效，无需重启。

## 6. 设置备份与迁移

选项页最底部**备份**分组：

- **导出**：把全部设置（含同步存储里的同步偏好与你的自定义面板指令）打包为带日期戳的 JSON 下载。
- **导入**：选择之前导出的 JSON，确认后按**合并语义**写回——文件里有的键覆盖，没有的键保持现状。换电脑、重装浏览器前导一次即可。

## 7. 隐私说明

- 一切数据（书签缓存、访问统计、搜索历史、死链/重复快照）只存在浏览器本地存储，没有任何外发。
- 访问统计可随时停采（`statsEnabled`）并一键清空；搜索历史可关闭并清空。
- `history` 权限是**可选权限**，仅在你主动启用"最近访问/历史导入"时才会请求；拒绝后相关分区自动隐藏，其余功能不受影响。
- 死链扫描只向你书签里的 URL（以及你自己配置的代理模板）发请求。
