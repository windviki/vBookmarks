## 1. 视觉体系（V 系列）

### 1.0 语言总纲：Calm Instrument（克制的仪器感）【k3】

vBookmarks 是「打开即搜索」的高密度工具：400px 弹窗里最多同时存在搜索栏、6 个视图标签、28px 行高的长列表、双层标记。它的美感应来自**秩序**而非装饰。三条原则：

1. **一个几何， themed 材质（One geometry, themed materials）**。全部主题共享同一套几何——圆角尺度、槽位、留白节奏、状态形状完全一致；主题之间只换材质（色板、纹理、光泽）。几何统一保证五个主题永远对齐同一套契约测试；材质差异让每个主题有自己的性格，且新增主题只写一份材质表。
2. **层级靠表面，不靠阴影**。小面积高密度界面的层级用**表面色阶**（`--vbm-canvas` 窗体 → surface 卡片 → selected 选中）加**发丝边框**表达；投影只留给真正的浮层（右键菜单、对话框、命令面板、toast）。列表内部零阴影，是 calm 感的来源。
3. **动效守时**。两档时长 `--vbm-dur-1: 120ms`（hover/按下/状态切换）、`--vbm-dur-2: 180ms`（浮层进出、视图切换），统一缓动 `--vbm-ease: cubic-bezier(0.2, 0, 0, 1)`（快出慢停，仪器阻尼感）；只动 `opacity`/`transform`/背景色；`prefers-reduced-motion` 收口为一条全局通配（现有散点规则合并，写入主题文件头注释）。动效只做「状态到状态的引导」，不做位移编排——工具不做秀。

### 1.1 三平面深度模型（canvas / surface / overlay）【glm53 · F1】

卡片化的根基。全 UI 只有三个深度平面：

| 平面 | token | 用途 | light | dark | ink | paper | classic |
|---|---|---|---|---|---|---|---|
| **canvas 画布**（窗口底） | `--vbm-canvas`（新） | body 背景、搜索行与卡片的留白区 | `#f6f7f9` | `#141518` | `#0a0d13` | `#efe9dc` | `#ffffff` |
| **surface 表面**（卡片/控件） | `--vbm-bg`（行面）、`--vbm-bg-elev`（浮层） | 视图卡、搜索框、菜单、对话框 | `#ffffff` | `#222428`（卡）/`#26282c`（浮层） | `#171c28` | `#fffdf7` | `#ffffff` |
| **overlay 覆盖** | `--vbm-elev-1` / `--vbm-elev-2` 两档投影（`0 2px 8px` / `0 8px 24px var(--vbm-shadow)`） | 真浮层（菜单/对话框/palette/toast）的投影，替换散写 box-shadow；晕环与纯装饰类不动 | 仅 `--vbm-shadow` 浓度按主题 |||||

规则：
- `--vbm-bg` 语义微调为「**行所在表面**」（列表行、hover/selected 叠色、标记晕环引用它）；`--vbm-bg-elev` 是「**浮起表面**」（菜单/对话框/下拉，永远盖在卡片之上）。行面与浮层面分离后，卡片色与菜单色独立调。
- **body 与大面积留白一律 `--vbm-canvas`**；卡片、输入框、菜单、对话框一律 surface。禁止「白色卡片浮在白底上」。
- 标记晕环（sync 点 / dead ×）现引用 `--vbm-bg`——卡片化后行在 surface 上，晕环跟随 `--vbm-bg` 自动正确，无需改。
- classic canvas = surface = `#ffffff`：平面坍缩为一张纸，正是 v3 的视觉。

**迁移要点**：`body { background-color: var(--vbm-bg) }` → `var(--vbm-canvas)`；逐个检查引用 `--vbm-bg` 做「页面底色」的规则改为 canvas。dark 的 `--vbm-bg` 随卡片调亮半档（§1.5.1）时，连带核对 dark 下引用 `--vbm-bg` 的非列表组件（横幅、小面板）变色是否符合预期。滚动条 thumb 不变。

### 1.2 4px 基准网格 + 间距 token【glm53 · F10】

实测当前**主体**行/槽/距指标已在 4px 网格上：行高 28、缩进步进 24、图标槽 20、间隙 4、gutter 8、文本轴 40、动作槽 24。4.1 写成规则：

- 一切间距、槽位、行高、内边距取 `4px × n`。
- **例外（明文登记，豁免清单随清理减表）**：1px 边线/分隔线；2px 指示条/焦点环/焦点环偏移/卡片行内缩等光学微调；行内 1.5px 图标描边；dnd 插入线 3px（现状视觉值）；双行行图标 18px/槽 22px（4.0.5 的视觉甜点，槽 = 图标 + 4px，间隙律不破）；sync 点 6px / dead × 10px 标记尺寸；`--vbm-shell: 6px`（弹窗外缘留白，400px 宽下「有空气又不浪费」的实测甜点）。
- 间距 token：`--vbm-space-1: 4px`、`--vbm-space-2: 8px`、`--vbm-space-3: 12px`、`--vbm-shell: 6px`（standalone 页局部覆写 12px，§5.1）。
- **契约测试**：`tests/design-system.test.js`（新）扫 neat.css 的 `padding/margin/gap/height/width` 声明值，白名单与上列例外之外非 4 倍数即失败（存量违例先登记豁免清单，随清理减表）。

### 1.3 半径阶梯 + 同心圆角律【两边一致】

```css
--vbm-radius-xs: 2px;     /* 状态指示条、dnd 线、徽标内衬 */
--vbm-radius-sm: 4px;     /* 行内控件：row-btn、seg、chip、行 hover/selected 背板 */
--vbm-radius: 8px;        /* 标准控件：输入框、按钮、菜单、对话框、下拉 */
--vbm-radius-lg: 12px;    /* 容器卡片：视图卡 */
--vbm-radius-pill: 999px; /* 计数药丸、圆钮 */
```

- **同心律**：嵌套圆角满足 `内半径 = 外半径 − 内边距`（视图卡 lg 12 − 卡内 4px = 控件 8 ✓）。写进宪法，新增嵌套结构时校验。
- **半径阶梯可被主题整体覆写**：light/dark 用默认；ink 覆写 `--vbm-radius-lg: 8px`（仪器克制）；paper 覆写 `--vbm-radius-lg: 4px; --vbm-radius: 4px`（印刷切块感）；classic 除 pill 外归零（§1.5.3——pill 是圆形徽标，不属圆角语言）。主题文件只改 5 个变量，零逐元素覆盖。
- 收敛映射表（现存硬编码半径 → token）：`6px`（横幅/小面板）→ 按角色 `--vbm-radius`/`--vbm-radius-sm`；`3px`（seg/小件）→ `--vbm-radius-sm`；`4px`（row-btn/chips）→ `--vbm-radius-sm`；`7px`（tab-badge）→ `--vbm-radius-pill`；`2px`（dnd）→ `--vbm-radius-xs`；`50%` 圆形类保留。收敛后契约测试断言无裸 `border-radius: 2/3/6/7px`。

### 1.4 排印与数字【glm53 §1.5 收录】

- 字号两档 token：`--vbm-text-sm: 11px`（meta/徽标）、`--vbm-text-md: 12px`（历史头/工具栏/次级）；正文沿用 `font: menu`（~13px）。不引入更多档位——弹窗里每多一档就多一处不一致。
- **一切数字 `font-variant-numeric: tabular-nums`**：计数药丸、结果数、相对时间、dead/dupes/stats 计数、扫描进度（现仅 3 处在用，扩到 `.tab-badge`/`.row-badge`/`.history-meta`/`.history-time`/各计数）。数字列不随位数抖动——全主题生效（原 ink 签名的「等宽数字」升格为全局纪律，§1.6.2）。
- 标题省略号维持 `text-overflow: ellipsis`（滚动条契约的一部分，不可动）。

### 1.5 表面卡片化 + tab 重绘【F1 + F2】

#### 1.5.1 视图卡片化

结构（CSS-only，无 DOM 改动）：

```css
#view-tabs, #views { background: var(--vbm-bg); }
#view-tabs {
    margin: 0 var(--vbm-shell);
    border: 1px solid var(--vbm-border);
    border-bottom: 0;
    border-radius: var(--vbm-radius-lg) var(--vbm-radius-lg) 0 0;
}
#views {
    margin: 0 var(--vbm-shell) var(--vbm-shell);
    border: 1px solid var(--vbm-border);
    border-radius: 0 0 var(--vbm-radius-lg) var(--vbm-radius-lg);
    overflow: hidden;
    flex: 1; min-height: 0;
}
```

- 两个元素**焊成一张卡**（glm53 R2）：tab 条是卡片头，视图区是卡片身；`#view-tabs` 的 `border-bottom` 取消后，头/身分隔由 `#views` 自身顶边框承担（卡内 1px `--vbm-border` 发丝线）。
- `#tree`/`#results`/各列表容器背景改 `transparent`（行面由卡片提供），移除 inset shadow（分隔职责移交卡片边线）。
- **dark 的卡片面**：`--vbm-bg` 调至 `#222428`（比 elev 略沉、比 canvas `#141518` 亮），elev（菜单/对话框）保持 `#26282c` 确保浮层比卡片亮半档。ink/paper 现值分离度已足。
- **滚动条**：卡片 `overflow:hidden` + 列表自身 `overflow-y:auto` 维持滚动条契约；`verify-scrollbars.js` 全矩阵重跑为硬门。
- 卡片内行的呼吸：列表容器 `padding: 3px 0` 改为 `var(--vbm-space-1)` 上下留白（入网）+ 左右各 2px 内边距让行整体内缩（光学呼吸，§1.2 登记例外）——行不再贴卡片边缘，这是「卡片感」成立的关键细节。
- 行 hover/selected **圆角背板**（`--vbm-radius-sm`、行盒全宽、零回流）：圆角只画在背板背景上，行几何不动——钉住行对齐与滚动条契约；背板随行内缩，不贴卡片边。首末行贴卡角的圆角由卡片 `overflow:hidden` 光学衔接（同心律不适用行背板，明文豁免）。

#### 1.5.2 tab 条重绘（F2：焊接卡头 + 分段式软填充，移除滑动底条）【结构 glm53 / 语言 k3】

**定案**：tab 条 = 焊接卡的头（§1.5.1）；active tab = **圆角软填充**（segmented）；移除 `.tab-indicator` 底条。

- `.view-tab`：几何不变（`flex:1`、容器查询标签显隐机制照旧），高度维持 32px；填充上下各内缩 3px（`border-radius: var(--vbm-radius)`），`transition: background-color var(--vbm-dur-1) var(--vbm-ease), color var(--vbm-dur-1) var(--vbm-ease)`。
- hover：`background: var(--vbm-bg-hover)`。
- active（`aria-selected="true"`）：`background: color-mix(in srgb, var(--vbm-accent) 12%, transparent); color: var(--vbm-accent);`，字重不加粗（避免宽度抖动导致 6 个 tab 互相推移）。
- **移除 `.tab-indicator`**：① 物理冲突——焊接卡后底条 `bottom:-1px` 压在卡片上边框；② 信号冗余——软填充 + accent 文字已是完整 active 表达；③ 67px tab 上 2px 底条滑动几乎不可感知。view-manager 里 indicator 定位/滑动逻辑同步删除，`aria-selected` 语义不变。
- 头/身分隔线由 `#views` 顶边框承担（§1.5.1），active 填充不贴轨道边缘。badge 药丸在 active 填充上保持 `--vbm-danger` 不变（danger 在 12% accent 底上对比充足）。

#### 1.5.3 classic 主题（token 级覆盖）【两边一致 · F11】

classic 是 v3.x 方形时代的致敬，只做浅色。

```css
body[data-theme="classic"] {
    /* 几何归零：v3 是方形世界（pill 保留默认 999px——圆形徽标不属圆角语言） */
    --vbm-radius-xs: 0; --vbm-radius-sm: 2px; --vbm-radius: 2px;
    --vbm-radius-lg: 0;
    /* 材质：v3 的强灰边、白底、无色阶 */
    --vbm-canvas: #ffffff;
    --vbm-bg-hover: #e8f0fe;        /* v3 记忆色 */
}
/* 贯穿式搜索栏：通栏、贴窗口左右缘 */
body[data-theme="classic"] #search { margin: 0; }
/* 卡片拍平：去外框，只留头/身一条分隔线 */
body[data-theme="classic"] #view-tabs { margin: 0; border-radius: 0; border-color: transparent; }
body[data-theme="classic"] #views { margin: 0; border-radius: 0; border-color: transparent; border-top-color: var(--vbm-border); }
```

- 因为 §1.3 的分层 token 先行落地，「方形化」在 token 层一处生效，全组件跟随——这是否决 ds 逐元素覆盖表的理由。
- tab 沿用全局分段语言，随半径归零呈方形填充（v3 式下划线指示条不复活——与全局移除 `.tab-indicator` 的决策一致）。
- 浮动两按钮（`#quick-add-btn`/`#tool-btn`）：方形 + 透明底 + hover `--vbm-bg-hover`，与搜索框同高贴合成组。
- classic 不参与 auto 映射（系统深色下仍保持浅色——classic 的承诺是「回到 2013 年的样子」）；在 `/theme` 列表中正常列出、可 `/theme classic` 直选。
- `store.js` theme 合法值列表加 `classic`；options 主题下拉加项（§1.10 A7）。
- 与「一键恢复经典界面」开关**正交**：一个管几何/材质，一个管功能集；两开 = 完整 v3 体验。

### 1.6 主题材质（每主题独立性格）【k3 签名 + glm53 状态表】

#### 1.6.1 light / dark ——「Modern」

全量采用 §1.1–1.5 新几何。light 保持 Material 系干净表面；dark 卡片/字段边框用 `rgba(255,255,255,.10)` 发丝线，**禁用投影**——暗主题深度来自色阶。

#### 1.6.2 ink ——「仪器 / Instrument」

两个签名细节（现有定义保留强化；「等宽数字」已升格为全局纪律，见 §1.4）：
1. **磷光晕**：焦点环/active tab/选中行带极轻外发光——`box-shadow: 0 0 0 1px color-mix(in srgb, var(--vbm-accent) 35%, transparent), 0 0 8px color-mix(in srgb, var(--vbm-accent) 22%, transparent)`。面积克制，像示波器辉光而非霓虹。
2. **仪器网格底纹**：body 背景叠 CSS 生成 1px 网格（双向 `repeating-linear-gradient`，24px 间距，accent 4%）。纯 CSS 零位图，只限 canvas 平面（不进入卡片与字段内部）。

几何上 ink 卡片半径降一档（`--vbm-radius-lg` → 8px，§1.3）。

#### 1.6.3 paper ——「纸器 / Stationery」

三个签名细节：
1. **纸纹**：body 叠 CSS 生成极轻颗粒（两层 `repeating-conic-gradient`，2–3% alpha 暖灰），只限 canvas 平面。
2. **纸张卡片**：`#views` = `bg-elev #fffdf7` + 顶部受光 + 暖色发丝边框；半径随阶梯覆写收 4px（§1.3，纸张不追求大圆角）。
3. **朱砂竖条选中**：选中行 = 左缘 2px 朱砂竖条 + 极浅暖色 wash（`color-mix(in srgb, var(--vbm-accent) 7%, transparent)`）。**否决 paper 渐变**（印刷油墨的平面性，glm53 R11 论证）。

#### 1.6.4 auto

映射逻辑不变（亮→`:root`、暗→dark）。否决「auto 深色映射 ink」开关（k3 K4 + glm53 2.10 一致）——auto 的承诺是「可预测的跟随系统」。

### 1.7 状态语言（V4：hover / selected / focus / flash / dnd）【k3 几何 + glm53 token 表】

**几何全主题统一**：卡片内行状态 = 行盒全宽圆角背板（`--vbm-radius-sm`；列表容器已整体内缩 2px，背板不贴卡片边，§1.5.1）；非卡片场景（菜单项、palette 行）直角平铺。焦点环保留 `2px solid var(--vbm-focus-ring)`、`outline-offset: -2px`，环随控件半径。

**材质按主题**（token 表，glm53 R11 落地为可断言）：

| 状态 | light / dark | ink | paper |
|---|---|---|---|
| hover | `--vbm-bg-hover` | 同左 + 0.5 档磷光叠底 | 暖灰 `--vbm-bg-hover` |
| selected | `--vbm-bg-selected` + `--vbm-fg-selected` | 深蓝底 + 磷光细边 | 朱砂左竖条 2px + 7% 暖 wash |
| focus-visible | focus-ring 2px | focus-ring + 磷光晕 | focus-ring（暖） |
| flash | `--vbm-flash` | 同左 | 同左 |
| dnd 插入线 | `--vbm-fg` 3px | accent 3px + 磷光晕 | `--vbm-fg` 3px 墨线 |
| dnd 文件夹高亮 | `--vbm-flash` 底 + accent 边，半径 `--vbm-radius-xs` | 同左 + 磷光 | 暖 flash 底 + 朱砂边 |

classic 状态色取 v3 记忆值（hover `#e8f0fe`、selected `#d3e3fd` + `--vbm-fg-selected`），几何随半径阶梯归零呈直角背板。

**语义色纪律**：`--vbm-danger`/`--vbm-warning`/`--vbm-success` 只用于语义（破坏性/警示/成功），永远不做装饰色（4.0.5 danger 收口的延续，契约测试维持）。

**实施约束**：状态规则几何部分留 neat.css（共享），材质部分随 §1.11 解耦进 `css/themes/<theme>.css`——几何契约一份断言、材质差异各表其面。

### 3.1 C1 搜索字段过滤 token【两边一致六键，F7 删 visited】

| token | 语义 | 数据源 |
|---|---|---|
| `site:github.com` | URL 主机包含（子域自动命中，主机 endsWith 边界匹配） | 索引 url |
| `folder:工作` | 祖先文件夹标题包含 | 路径映射（`buildPathMap`/`pathOf`） |
| `title:词` / `url:词` | 限定匹配通道 | 索引字段 |
| `dead:` / `blocked:` | 死链/阻断（基于 `deadLastScan` 缓存；从未扫描 → 提示行「先运行一次死链扫描」） | 扫描缓存 |

- **删除 `#标签`（F14）与 `visited:N`（F7）**：标签体系不存在；visitStats 只计弹窗打开数，语义撑不起过滤词。
- token 形态 `prefix:value`，`prefix` 表固定枚举；无法识别的 `xxx:yyy` **不当 token**（整串照常 fuzzy）。
- 解析层是纯函数 `parseSearchTokens(query)`（新 `src/search-tokens.js`，fuzzy-core 保持纯净）；`<mark>` 高亮只作用于 fuzzy 剩余词命中（token 是过滤条件不是匹配内容）。
- **omnibox 不启用 token**（fuzzy-core 纯净、omnibox 行为不变，parity 契约不破）；搜索历史存原始串。
- 空 fuzzy 查询 + 有 token = 纯过滤模式，结果按 `dateAdded` 降序。
- C2 多词 AND 先落地，C1 剩余词复用其分词结果。

### 3.2 C2 多词 AND 分段匹配

- `rank()` 对空格分词：各词独立子序列评分，全部命中才返回；总分 = 各词分相加 + 连击加成；顺序不敏感。
- `<mark>` positions 跨词合并（并集排序）。
- omnibox 侧经 search-core 共享 fuzzy-core，行为自动一致（4.0.5 统一红利）。
- 边界：单词查询路径与现状逐字节一致（回归测试锁死，避免排序漂移惊扰存量用户）。

### 3.3 C3 URL 直开 + `/copy`

| 项 | 定案细节 |
|---|---|
| **URL 直开** | 平铺查询命中 `^https?://\S+$` 或裸域名形态（含 `.` 且无空格）→ 首位「打开 URL」行（earth 图标），Enter 直开；URL 行置顶、书签命中照常列出；与 slash 分支天然不冲突；URL 经校验后交 `chrome.tabs.create`，`javascript:`/`data:` 形态不触发 |
| **`/copy title\|url\|path\|markdown`** | 作用于当前聚焦行（树/结果/列表行统一经 `rowFocusTarget` 契约取行）；无聚焦行时 disabled 态说明；`markdown` 产出 `[title](url)` |

## 4. 通知系统重构【k3 · F4 静态 JSON】

### 4.1 端点决策

**定案**：公告数据放仓库 `docs/announce.json`，客户端经 `raw.githubusercontent.com/windviki/vBookmarks/master/docs/announce.json` 拉取。

- **vs Upstash**：零密钥（ds/glm53 方案需内置只读 token，密钥入仓即负债）；零新服务依赖与账号；公告内容走 git PR 评审与发版流程天然一体（发布 checklist 加「更新 announce.json」）；消除隐私观感与商店审核风险（书签管理器外呼第三方端点是最差观感，拉取自己开源仓库的静态文件完全透明）。raw 域名约 5min CDN 缓存对公告场景无影响。
- **CSP/权限**：`connect-src *` + `<all_urls>` 已覆盖，零 manifest 变更。

### 4.2 数据模型（`docs/announce.json`）

```json
{
  "version": 7,
  "messages": [{
    "id": "v410-whats-new",
    "minVersion": "4.1.0", "maxVersion": "",
    "channel": "all",
    "once": true,
    "display": "banner",
    "kind": "tip",
    "titleKey": "announceV410Title", "textKey": "announceV410Text",
    "textFallback": { "en": "…" },
    "link": { "labelKey": "donationV4GuideLink", "url": "https://github.com/windviki/vBookmarks/blob/master/docs/guide-v4.md" }
  }]
}
```

- 顶层 `version` 单调递增；客户端 GET，`If-None-Match` 由 raw CDN 的 ETag 免费支持，本地存 `etag`（ETag 不可用时回退比较顶层 `version`，§4.3）。
- 多语言：i18n key 优先（随版本打进 `_locales`），`textFallback` 仅 en 兜底。
- `display`：`banner`（risk-banner 式行内横幅，进 Tab 环）/ `dialog`（AlertDialog）/ `toast`（toastAction）。默认 banner。**枚举保持三值**；引导类消息用可选 `"kind": "tip"` 标记，参与 §4.4 频率纪律。
- dismiss 不设独立字段：由 `id` 派生（`vbmAnnounceSeen` 记录 id，§4.3）。

### 4.3 客户端（`src/announce.js`，纯逻辑可测）

- 触发：popup/sidepanel 打开时；先读 `storage.local` 缓存 `vbmAnnounce = { ts, etag, data }`，**TTL 6h** 内不联网。
- 拉取：`fetch(url, { headers: { 'If-None-Match': etag }, signal: AbortSignal.timeout(4000) })`；304 → 只刷新 ts；**一切失败静默**。
- 过滤：`compareVersions` 版本区间 ∩ channel ∩ once+未 dismiss；多条按数组序取第一条（优先级 = 数组序）。
- 调度：同帧与捐赠卡冲突时**捐赠卡优先**（本地体验优先于远程公告），公告顺延到下次打开；channel 枚举 `all|popup|sidepanel`（standalone 视同 popup；options 不参与）。
- 关闭：id 记入 `vbmAnnounceSeen`（上限 100 条 LRU，once 语义），banner × 进既有键盘模型。
- **隐私开关**：选项页 General 组加 `announceEnabled`（默认开）；关闭则零联网。
- 4.1.0 之前的三条既有横幅（捐赠/风险/history 权限）不动，公告层是纯增量。
- **安全**：`fallback` 纯文本、渲染走 `escapeHtml`（`src/escape.js`）；`display` 只取枚举三值；`text` 上限 500 字符；数组上限 10 条。

### 4.4 功能引导 tooltip

- 形态：`"kind": "tip"` 的 banner 消息——单行横幅：图标 + 一句文案 + 「试试」动作链接 + ×（`display` 枚举不新增值，渲染复用 banner 通道）。
- **频率纪律**（写死进 announce.js）：每个 major.minor 至多展示 1 条 tip；同一用户同时存活 tip 至多 1 条；全部 once + dismiss 持久化。违反纪律不得合入。
- 4.1.0 首发内容：`/theme` 列表与新视觉（与 v410-whats-new 合并为同一条）。

### 4.5 发布流程

`AGENTS.md` Release process 增补一步：发版 PR 更新 `docs/announce.json`（version 自增 + 新 message）→ CI 加 schema 校验（`tests/announce.test.js`）。临时通知 = 单独提一个只改 announce.json 的 PR。
